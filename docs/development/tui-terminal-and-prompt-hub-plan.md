## 一、 设想与目标定位

用户设想的核心诉求：
1. **右侧面板终端化**：将右侧原本单一的“网页对话聊天窗”，改造成或扩展出可直接运行本地 **TUI AI**（如 Claude Code、Codex CLI、Gemini Antigravity 或自定义 Python/Rust 智能体）的**原生交互终端**，实现“终端对话 + 画布实时联动排布分镜”。
2. **桌面工作台主页重构**：彻底剥离上游 Web SaaS 的公网首页、CDN 宣传 Banner、云端登录等残余代码，重构为符合影视剪辑与 AI 编导习惯的**“本地导演工程管理中心”**。
3. **提示词仓库动态接入与实时 URL 调度**：激活并泛化后端现有的 GitHub 抓取与 Cron 调度机制，允许用户配置任意 GitHub Raw URL 或本地参考仓库路径，支持手动即时刷新与定时更新，为画布分镜与生图提供最新提示词支撑。
4. **自主分支治理与长期二次开发**：确认以 `chenyuxiaojin/infinite-canvas` 为唯一主干，明确 MIT/AGPL 边界，确立对上游的“单向组件采石场（Cherry-pick Only）”关系。

## 三、 四大模块具体实施方案

### 模块 1：右侧面板终端化（TUI AI 嵌入与双模切换）

#### 1.1 现状与改造点
* 现有的 [`canvas-assistant-panel.tsx`](file:///Users/chenhuajin/项目/自己的应用/infinite-canvas/web/src/app/(user)/canvas/components/canvas-assistant-panel.tsx) 是一个标准的 Web Chat 抽屉。
* **双模设计**：在抽屉顶部加入切换开关：`[ 💬 简易助手 ]` 与 `[ 💻 终端工作台 (TUI) ]`。
* **Tauri PTY 原生管道**：
  * 在 `desktop/src-tauri/Cargo.toml` 引入 `portable-pty = "0.8"`。
  * 在 `desktop/src-tauri/src/terminal.rs` 实现系统终端 spawn / read / write / resize。
* **Web 端渲染**：引入 `@xterm/xterm` 与 `@xterm/addon-fit`，以深色自适应主题渲染终端。
* **双向联动**：
  * 画布选中的图片/分镜可一键复制路径或引用到终端输入区；
  * 终端中运行的 Claude Code / TUI AI 通过项目的 MCP 或本地 `infinite-canvas` CLI 直接驱动画布生成分镜卡片。

---

### 模块 2：主页彻底重构（导演工程中心）

* **移除公网残留**：彻底清理 `web/src/app/(user)/page.tsx` 中的营销 Banner、外部 CDN 广告、云端市场推广、多租户登录入口。
* **重构为本地导演工程台**：
  1. **片子工程矩阵**：以案例（如《美甲师日常》、《国运末世》、《克兰奇杀妻案》）为卡片管理画布，展示镜头数、关键帧首帧进度、达芬奇联动状态。
  2. **外部集成状态条**：直观展示本地运行时（3100/3101）、Agent Bridge（3102）、DaVinci Resolve（达芬奇）、Eagle 素材库、本地 FFmpeg 的联通绿灯。
  3. **提示词与资产快捷操作**：提供一键同步提示词库和资产导入导出入口。

---

### 模块 3：提示词仓库动态接入与实时 URL 调度系统

* **扩展动态订阅源**：扩充模型，允许在前端或配置中自由添加：
  * GitHub 远端 Raw URL（如 `https://raw.githubusercontent.com/.../README.md`）
  * 本地目录路径（直接连接 `AI编导/参考仓库`，如 `Seedance-2.5`、`MiniMax-H3` 等本地技能与提示词）
* **影视分镜专用提取器**：增加针对镜头语言、运镜动词、景别光影的专业解析器。
* **调度与即时拉取**：
  * 提供 `POST /api/prompts/sync` 接口与前端“即刻刷新”按钮；
  * 具备 Cron 定时增量更新与 Hash 防重机制。
* **画布端快速消费**：在分镜卡片输入框中通过 `/` 或快捷键即时检索最新提示词并一键填入。

* **确立事实主干**：以你本地及个人 GitHub 远程 `chenyuxiaojin/infinite-canvas` 为唯一主干。
