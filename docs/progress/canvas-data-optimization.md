# 画布数据与请求可靠性优化

本报告对应 [PRD 第 9 节](../overview/product-requirements.md) 的版本历史、资料库分页、取消与超时。主整合已统一构建、安装 Rust 正式 App，实际数据与剩余原生操作见 [整合验收](canvas-rust-repair.md)。下文隔离证据不代替正式交互；本专项没有回滚用户真实项目或调用真实模型/媒体生成。

## 当前交付

- `integrations/local-agent-adapter-rust/src/history.rs`：持久快照、版本清单、差异、事务恢复和幂等请求。主整合已将人工保存及 Agent apply 的成功事务接入 history；CAS 失败不会写成功历史。独立历史组件已由前端任务接入页面，恢复经 store 串行入口并携带预览时的 baseRevision。
- 快照保留 JSON 的节点、关系、对话和未知字段。原媒体不复制、不压缩、不删除；只保存原有稳定引用。恢复保留当前绑定相关字段和创建时间、保留恢复前快照、产生新时间及恢复来源；清除待执行 Agent 请求，历史运行状态转为停止，原 Task ID 保留供核对。
- 首次记录旧内容与第一次新保存；后续普通编辑至多每 30 秒一版。每项目最多 100 条 / 64 MiB 快照逻辑数据，至少保留最新两条，因此单个巨大项目可超过软字节上限；不缩减原 JSON、不清理素材。仅修剪本功能的快照；SQLite 文件可能保留可复用空页，不对用户数据库运行 VACUUM。每项目保留最近 1,000 条恢复幂等收据，较早请求仍须经过当前修订校验。
- `prompts.rs/assets.rs/query.rs`：SQL 内多标签 OR、COUNT、LIMIT/OFFSET；单次响应在同一读事务内组装，避免收藏/同步/并发更新把总数与页面混成不同状态。标签集合继续在标签过滤前、按原排序首次出现顺序产生，仅扫描/解析 tags，不解码全部项目正文。分类与收藏含义保持。启动建立四个排序索引，不修改既有目录数据。
- `request-lifetime.ts` 与 API 代理：传递 AbortSignal，取消、读取超时、连接失败、流意外中断分别处理；300 秒为无数据等待期限，并非总时长。取消/异常/正常 EOF 均清理定时器和读取器。请求编号在前后端等待边界保持；写入等待中断提示可能已提交，不自动重试。
- Rust 媒体代理改为异步 reqwest 流，删除脱离响应生命周期的阻塞读取线程。30 秒连接/解析期限、300 秒读取空闲期限；每次重定向重新检查并固定公网解析地址，禁用系统代理及自动压缩转换。Range、MIME、长度、原字节保留。响应被丢弃时上游读取连接释放。媒体代理只发 GET，不涉及付费任务重发。
- 提示词无限列表使用查询框架的取消信号；公共 GET/POST/DELETE 与素材查询接受信号，主动取消不再统一变成连接失败。

### 查询性能范围

环境：Apple M4 Max，36 GiB 内存，macOS 26.6.2，Rust debug 构建、内置 SQLite，本机临时数据库；真实目录 1,773 条基础上增加 20,000 条，默认页面 20 条，5 次循环。

同次隔离运行：旧算法 813.300 ms，新算法 410.693 ms（总耗时约减少 49.5%）。完整 Prompt 解码从全部匹配项降至 20 条，标签 facet 仍须扫描匹配 tags。这里只证明该数据查询场景，**不代表原生画布帧率、内存或正式 App 总体提速**。旧算法与新算法的并列测试保留在 Rust 源码，允许复跑；实时负载会影响绝对耗时。

上述专项执行时只使用隔离副本；对应临时服务已关闭。主整合随后完成正式 3101 替换，见整合报告。浮点精度补充使用实际外部小数字面量验证保存、重开和序列化，修改前一位误差、修改后通过；最终 API 19 项、adapter 22 项通过。日志已归档至相邻私有备份的 `repair-rust-20260905/integration-evidence/float-full-*.log`。

## 接入与待验收

- 主整合持有 `canvas.rs`、`use-canvas-store.ts`、桌面 IPC 注册及安装输出；历史组件只能调用 `restoreVersion(projectId, sequence, preview.baseRevision)`，不能自行替换 store 项目或绕过队列。
- 前端任务持有页面接线和素材临时缓存生命周期；保留所有持久素材，历史引用不会因当前画布缺少消费者被删除。
- 正式 App 仍需在副本项目验证历史列表、差异文案、恢复后撤销/重做、重启、并发编辑提示与原图打开；不能在用户真实片子上试回滚。
- 正式网络断线、慢远端媒体和 WebView 关闭的完整端到端资源回收仍需原生验收。前端无法仅凭网络失败证明远端进程已退出，文案明确为“可能已退出”；流中断和首次连接失败分别报告。
- 桌面本地 IPC 原文件读取仍沿用现有实现；本轮异步取消优化覆盖 HTTP 媒体代理，不能把它宣称为所有本地 IPC 都可中途取消。
- Antigravity 修复后的真实工具调用仍未复验，本任务未重复消费额度。
