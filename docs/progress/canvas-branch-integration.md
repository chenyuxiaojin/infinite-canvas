## 冲突处理

- Bridge 普通操作继续使用主线 SHA-256 版本和请求幂等；公共协作 reducer 在事务内处理锁、任务及审计。协议任务保留旧数字版本输入兼容，当前文档读取仍返回内容哈希。桌面保存继续检查内容哈希并保留历史。
- 主线的本地保存失败恢复、删除墓碑、浮点往返、视口/面板保存和原图 ZIP 导出保持；未恢复 Go 打包或 App 账号云同步。
- 新增本机媒体服务及人工确认入口，合并后的节点通过现有原图读取和受控流式媒体接口显示。
- 保留主线新目录、延迟加载侧栏和拖动实现，接入人工锁、审计状态、视频卡片、场次聚焦和顺序预览控件。
- 原有回归测试和旧分支协议测试同时保留。隔离测试加载真实新增 reducer；测试节点补齐类型要求，模拟请求 ID 改为唯一值。
